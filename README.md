# AMAT5315-2026Fall-Exercise

Weekly exercises for AMAT5315 Modern Scientific Computing at HKUST(GZ).

## Week 3

The `week3/` directory contains a tested Rust implementation of the two-dimensional Ising model with Metropolis and Wolff samplers, reproducible raw-data contracts, statistical error analysis, and scientific evidence figures.

See [week3/README.md](week3/README.md) for the environment, reproduction commands, and limitations of the critical-temperature estimate.

## Week 4

The `week4/` directory contains the tested Rust Fourier solver for periodic incompressible flow, its line-equation stability and accuracy checks, reproducible simulation scripts, and evidence figures.

See [week4/README.md](week4/README.md) for the environment, reproduction commands, numerical checks, and solver limitations.
